로그인·가입은 기존 로그인 화면에서 처리합니다. 로그인하면 이 페이지로 자동으로 돌아옵니다.

로그인 화면으로 이동

① 주문 전체 읽기

orders 컬렉션 전체를 읽기 전용으로 조회합니다. 전체/타인 주문 건수와 함께 각 주문의 문서 ID·userId·totalPrice 를 표로 표시합니다.

아직 시도하지 않았습니다.

② 내 주문 금액 고치기

내 기존 주문 1건의 totalPrice 를 1 로 바꾸는 쓰기 테스트입니다. 버튼을 누르면 먼저 대상 주문과 원래 값을 읽어 보여 주고, 확인 창에 동의해야만 실제로 씁니다. 쓰기 성공 시 곧바로 원래 값으로 자동 복구를 시도하며, 복구에 실패하면 원래 값을 화면에 남겨 수동 복구할 수 있게 합니다.

아직 시도하지 않았습니다.

③ 상품 가격 0원으로

products/p1 의 price 를 0 으로 바꾸는 쓰기 테스트입니다. p1 은 실제 진열 상품이므로, 버튼을 누르면 먼저 원래 값을 읽어 보여 주고 확인 창에 동의해야만 실제로 씁니다. 쓰기 성공 시 곧바로 원래 값으로 자동 복구를 시도하며, 복구에 실패하면 원래 값을 화면에 남겨 수동 복구할 수 있게 합니다.

아직 시도하지 않았습니다.

④ 서버에게 금액 묻기

Callable 함수 calcOrderTotal 에 productId "p1", quantity 2 를 보냅니다. 「가격 바꿔 보내기」는 같은 요청에 price: 100 을 덧붙여 보냅니다. 서버는 Firestore 가격만 쓰므로 결과가 같아야 합니다.
